# AI Coding Agent Guidelines

Follow these core rules when contributing to this project:

- **Plan before coding**: Outline proposed changes and architectural choices before implementation.
- **Make small changes**: Keep edits granular, incremental, and focused.
- **Do not modify unrelated files**: Touch only the files relevant to the active task.
- **Explain changes**: Provide concise rationales for modifications and key choices.
- **Test changes**: Verify that the application builds and runs successfully after updates.
- **Use environment variables for secrets**: Never hardcode API keys, passwords, or tokens.
- **Keep code simple and readable**: Prioritize clarity, simplicity, and standard patterns over clever abstractions.
- **Follow existing project structure**: Adhere to established naming conventions and file directory layouts.
- **Ask before adding any new dependency**: Request explicit approval before installing or introducing external libraries.
- **Keep docs/api.md updated whenever endpoints change.**
- **Stack: React (Vite) frontend, Node/Express backend. Don't introduce other frameworks without asking.**
